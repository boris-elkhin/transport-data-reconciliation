#  Сверка и обогащение логистических реестров

ETL-пайплайн на pandas для автоматической сверки ручных реестров подрядчиков с выгрузкой из 1С:TMS.

## Проблема
Ручные реестры содержат грязные номера заявок и не имеют данных о маршрутах, типе груза и статусе. Отчёт 1С:TMS содержит эти данные, но тоже имеет неточности в номерах.

## Решение
Двухэтапный алгоритм объединения:
1. Точный мердж по Номер + Дата
2. Fallback-мердж по Дата + ТС + Код цеха

## Как запустить
1. python generate_data.py  создать синтетические данные
2. python main.py  запустить пайплайн
3. Результаты в папке output/

## Дисклеймер
Все данные синтетические, имитируют реальные бизнес-процессы.
